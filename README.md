# English Learning Lexicon with Etymology 

A structured, machine-readable dataset designed for English language learners (CEFR B2–C2), EdTech platforms, and NLP applications.

## 📦 Dataset Features
- **Structured Format:** CSV / JSON
- **Core Fields:** `word`, `pos`, `cefr_level`, `ipa`, `definition_en`, `etymology_note`, `germanic_root`, `example_sentence`
- **Pedagogical Alignment:** CEFR Standardized & Etymology-based logic mapping.
